# Comics Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native iPhone Duo app that reads xkcd, Questionable Content, Dumbing of Age, SMBC and PBF in one reader, never loses the reader's place, and takes its comic list from an updatable catalog file.

**Architecture:** SwiftUI app, no server. A JSON catalog describes each comic as data (an index source plus a strip extractor); a small set of recipe kinds in code interprets it. SQLite holds indexes, strip details and one bookmark per comic; images sit in a capped disk cache with read-ahead. Layout follows the live window size.

**Tech Stack:** Swift, SwiftUI, xcodegen, GRDB (SQLite), URLSession, NSUbiquitousKeyValueStore, XCTest/XCUITest.

**Spec:** `docs/superpowers/specs/2026-11-22-comics-design.md` (read it first; this plan argues from it).

## Global Constraints

- App name `Comics`, bundle `com.jsvana.comics`, team `7UE4RDLUSX`, iOS deployment target 18.0, `TARGETED_DEVICE_FAMILY "1,2"`, xcodegen `project.yml` modelled on `~/projects/quire/project.yml` (three targets: `Comics`, `ComicsTests`, `ComicsUITests`). `Comics.xcodeproj` is generated and gitignored.
- One package dependency: GRDB (`https://github.com/groue/GRDB.swift`, from 7.0.0). No HTML-parsing library; extraction is `NSRegularExpression` with named captures.
- Layout is chosen from the window size only: `wide` = width ≥ 700 and width > height; otherwise `narrow`. Designed sizes: 466×678 and 951×669.
- Strip ordinals are 1-based, assigned once, never renumbered. New strips append.
- Network manners: at most one in-flight request per host, a 250 ms gap between requests to the same host, and a generic client name as the User-Agent: the constant `HTTPClientIdentity.userAgent = "Comics/1.0"`. Read-ahead 10 strips (20 on unmetered Wi-Fi), keep 5 behind. Image cache cap 500 MB.
- No index parsing, image decoding or file writes on the main thread.
- Tests never touch the network, except the one opt-in `RecipeHealthTests` class.
- Test command (all tasks): `xcodegen && xcodebuild test -project Comics.xcodeproj -scheme Comics -destination 'platform=iOS Simulator,id=0C2C9EF0-78BA-46C6-8A2E-468C41D7F417' -derivedDataPath /Volumes/Storage/Xcode/comics-dd -only-testing:<Target>/<Class>` (the "iPad Wide Test" simulator). Simulator screenshots must be written to `/tmp`, never to `/Volumes/Storage` (simctl hangs).
- Commits: this machine has no global git identity. Reuse the author of the repo's existing commits by passing `-c user.name=... -c user.email=...` taken from `git log -1 --format='%an|%ae'`. End messages with the session's `Co-Authored-By` attribution line. Work on `main`.
- The repo will be public: never commit signing keys, API keys or personal data.

## Review Focus

1. **Bookmark after an abrupt kill.** Jay turns a page and the app is killed at once; on relaunch he expects that page. Pinned in Task 7 (`testBookmarkVisibleFromSecondConnectionImmediately`).
2. **Messy markup in a strip page.** Relative or protocol-relative image URLs, single-quoted attributes, HTML entities in hover text (`&#8217;`, `&quot;`); he expects the right image and clean text. Pinned in Task 5.
3. **A site's list changes under the app.** A strip is deleted or the archive page reorders so the last known key is missing; he expects the old index and bookmark untouched, not a renumbering. Pinned in Task 4 and Task 6.
4. **Odd images.** WebP (SMBC), animated GIF, a 20,000-pixel-tall strip, a 404 for a missing number; he expects a picture or a "couldn't load" card he can move past, never a crash or a stuck reader. Pinned in Task 9 and Task 11.
5. **Restore meets a different index.** iCloud holds a bookmark whose ordinal no longer matches the freshly built index, or whose key is gone; he expects the bookmark to follow the key, else clamp to the last strip. Pinned in Task 8.

### Task 2: Catalog model and the five-comic catalog

**Files:** Create `catalog/catalog.json`, `Comics/Catalog/Catalog.swift`, `ComicsTests/CatalogTests.swift`. Add `catalog/catalog.json` to the app target's resources in `project.yml`.

**Interfaces — Produces:**

```swift
struct Catalog: Codable, Equatable { static let supportedSchema = 1
  let schema: Int; let version: Int; let comics: [ComicDef] }
struct ComicDef: Codable, Equatable, Identifiable {
  let id: String; let title: String; let author: String; let home: URL
  let about: String; let shape: Shape; let index: IndexRecipe; let strip: StripRecipe
  enum Shape: String, Codable { case portrait, wide, mixed } }
enum IndexRecipe: Codable, Equatable {            // JSON discriminator: "kind"
  case numbered(Numbered), wordpress(WordPress), linkList(LinkList)
  struct Numbered: Codable, Equatable { let latestURL: URL; let latestPattern: String  // capture `n`
    let first: Int; let skip: [Int] }
  struct WordPress: Codable, Equatable { let api: URL }      // .../wp-json/wp/v2/<type>
  struct LinkList: Codable, Equatable { let url: URL; let itemPattern: String  // captures `key`, optional `title`, `date`
    let pageTemplate: String; let newestFirst: Bool } }       // "{key}" substituted
enum StripRecipe: Codable, Equatable {            // discriminator: "kind"
  case json(JSONStrip), html(HTMLStrip)
  struct JSONStrip: Codable, Equatable { let url: String; let page: String  // templates with {key}
    let image: String; let title: String?; let hover: String? }             // field names
  struct HTMLStrip: Codable, Equatable { let url: String                    // template with {key} or {page}
    let imagePattern: String; let titlePattern: String?                     // capture `v` in each
    let hoverPattern: String?; let bonusPattern: String? } }
```

Catalog contents (`schema` 1, `version` 1). URLs and markup facts come from the spec's "What the sites offer" table:
- `xkcd`: numbered, `latestURL https://xkcd.com/info.0.json`, `latestPattern "\"num\":\\s*(?<n>\\d+)"`, `first 1`, `skip [404]`; json strip `url https://xkcd.com/{key}/info.0.json`, `page https://xkcd.com/{key}/`, fields `img`, `safe_title`, `alt`; shape `mixed`.
- `qc`: numbered, `latestURL https://www.questionablecontent.net/`, pattern capturing the number from `<img id="strip" src=".../comics/5965.png">`, `first 1`, `skip []`; html strip `url https://www.questionablecontent.net/view.php?comic={key}`, image from `<img id="strip" src=...>`; shape `portrait`.
- `doa`: wordpress, `api https://www.dumbingofage.com/wp-json/wp/v2/comic`; html strip `url {page}`, image = the `wp-content/uploads` `<img>` inside the comic post, hover = that image's `alt`; shape `wide`.
- `smbc`: linkList, `url https://www.smbc-comics.com/comic/archive`, items `<option value="comic/slug">label`, `pageTemplate https://www.smbc-comics.com/{key}`, `newestFirst false`; html strip `url {page}`, image `<img ... id="cc-comic">` `src`, hover its `title`, bonus the `<img>` inside `<div id="aftercomic">`; shape `mixed`.
- `pbf`: linkList, `url https://pbfcomics.com/comics/`, items = links to `https://pbfcomics.com/comics/<slug>/` (exclude `feed`), `newestFirst` as observed in the fixture; html strip `url {page}`, image pattern worked out against the fixture (lazy-loaded: prefer `data-src`); shape `mixed`.

The exact regexes are finished in Tasks 4 and 5 against fixtures; this task writes best-effort patterns and locks the shape.

### Task 7: Place-keeping

**Files:** Create `Comics/Library/PlaceKeeper.swift`, `ComicsTests/PlaceKeeperTests.swift`.

**Interfaces — Consumes:** `Database`. **Produces:**
- `struct JumpEntry: Equatable, Codable { let ordinal: Int; let key: String; let at: Date }`
- `enum CardStatus: Equatable { case behind(at: Int, of: Int), new(Int), caughtUp }`
- `final class PlaceKeeper { init(db: Database); var onChange: ((String) -> Void)?`
  - `func bookmark(_ comic: String) -> Int`
  - `func step(_ comic: String, to ordinal: Int)` — next/previous; no history
  - `func jump(_ comic: String, to ordinal: Int)` — pushes the old position, keeps the newest 10
  - `func back(_ comic: String) -> Int?` — pops the newest history entry and moves there (no new push)
  - `func history(_ comic: String) -> [JumpEntry]` (newest first)
  - `func restore(_ comic: String, ordinal: Int, history: [JumpEntry])` — sets both without pushing (used by Task 8)
  - `static func status(bookmark: Int, count: Int) -> CardStatus` }`

Rules: every write is a synchronous committed transaction storing ordinal and key; ordinals are clamped to `1...count`; `status`: remaining = count − bookmark; 0 → `.caughtUp`; 1…30 → `.new(remaining)`; otherwise `.behind(at: bookmark, of: count)`. `onChange(comicID)` fires after each committed change (the cloud mirror hooks in here).

### Task 9: Image cache and strip loader

**Interfaces — Consumes:** `HTTPFetching`, `StripExtractor`, `LibraryStore`, `Database`, `ComicDef`. **Produces:**
